# ADR-010 dirty 内容、祖先传播与标签顺序

状态：已实施。

modified-star 比较当前只读快照和最近一次成功 init/read/save 的内容，undo 回到保存内容后星号消失；redo 再出现。新建节点立即 dirty，空 init 干净。节点比较包含逻辑类型、几何、文本、样式、父级和有序后代，所以部件改变也使祖先容器及画布标星。画布尺寸参与比较，删掉节点后剩余祖先/画布标星；无节点可以标注已删除项。

保存点和 id 指纹映射封装在 ModifiedStarDecorator 实例字段，不用模块变量。成功保存才通知，失败保存保留旧点；读取/新建替换保存点，标签只读文档。延迟首次渲染才订阅，来源回放最近保存点，失败注册不泄漏订阅。

同一行按注册顺序以空格拼接，当前装配 box-type-label 在 modified-star 之前，得到 (box) *。两个插件相互无依赖，新增标签不改渲染器或内核。精确内容比较避免哈希碰撞；代价是保留快照指纹且祖先重复比较，未将其声称为深树性能优化。

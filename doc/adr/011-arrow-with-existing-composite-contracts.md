# ADR-011 使用既有 Composite 契约接入 arrow

状态：已实施，位于既有 p2 标签之后。

## 背景

选做任务要求增加一种图形，验证内核无需修改。当前 SvgShapeInput 提供数值属性、样式和文本能力，未开放任意字符串属性读取。直接实现 polygon 的 points 读回需要扩大框架接口；本次选择原生线段组成的 arrow，使用已有接口即可完成。

## 决策

- ArrowPlugin 仅注册 ArrowProvider；ArrowSpec 创建 ArrowShape 容器及三个 LineSpec，派生 id 为 -shaft、-head-left、-head-right。
- create arrow 接收两端坐标及可选 stroke，默认 black。方向由非零有限长度的向量计算；头部沿轴长度为 min(20, length/3)，半宽为头长一半。短箭头按比例缩小头部，任意方向均可构造。
- 线段不设置自身 stroke，继承容器的 stroke/stroke-width，普通 set 即可改变整体外观，无需新增处理器。
- 使用 ContainerShape 现有移动、缩放、局部历史及最终结构策略；必要部件必须仍是直接 Line 子节点，禁止移走/删除/解组，允许附加节点。直接编辑子线段坐标属于手工调整，不自动重排箭头头部。
- 保存为 g + data-kind="arrow" 和真实三条线；已装插件恢复并验证部件，未装降级普通 g，保留可见轮廓。破损结构拒绝读入，不使用模板补造。
- 代码与配置装配加载同一类，内核、加载器、渲染器和已有插件不增加箭头分支。

## 取舍

三条线增加树节点数，stats 因而计为三个 line 叶子和一个容器；不把 arrow 计作单个叶子。轮廓箭头不提供填充箭头头部，也不自动附带文字。无专用标签时查询沿用物理 g 类型，通过主线的线段投影显示端点。

保留已有 p2/final 与对应指标，不移动标签或把本次实现写入历史验收结果。新增验证与报告单独记录。

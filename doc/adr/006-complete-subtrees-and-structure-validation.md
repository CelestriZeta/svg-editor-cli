# ADR-006：完整候选子树与最终结构预演

状态：CLI 重构第 5 步已采用。没有实现 box、属性处理器或树标签。

## 背景

单节点创建和逐项 SVG 插入不能保证复合容器在校验时已经拥有必要部件。结构命令又可能先插入空组再移动多个节点；逐个原子操作检查容器，会把合法的最终结果误判为非法中间态。

## 决策

- ShapeSpec 默认 children 为空；ShapeSpecWithChildren 通过不可变组合覆盖子规格，保留原规格的多态构造，不修改其数据。插件只使用公开规格和领域容器，不获得内部树。
- ShapeSubtree 在私有结构候选中构造全部节点，检查内部重复 id 和叶子非法子规格。ShapeRelationsBinding 向图形提供冻结只读门面，安装后切换至活动树，不让图形继续持有创建候选关系。
- ShapeStructureCandidate 复制活动树的关系、引用和顺序，预演整条命令的所有局部变更。最终检查全局 id、父子关系和所有仍存在的容器策略；删除整个复合子树时不再校验已经移除的容器。
- 容器通过 validateStructure(ShapeRelations) 定义同步、只读、确定性的结构约束。必须查询给定候选关系，不能用当前对象的 parent/children 代替尚未提交的状态。策略在最终目标父级上下文校验，不在未挂接的创建根上提前校验。
- ShapeStructureChangeSet 在准备、apply 和 revert 时分别预演相应最终结果；实际写入及逆序补偿仍由局部 ShapeTreeChange 和既有 CompositeChangeSet 完成。校验关系是临时副本，不存入 undo 历史，也不复制图形或属性值。
- ShapeTree.adoptSubtree 在检查完成后整体安装节点索引与内部关系；首次安装后插入变更释放暂存子树，redo 复用原对象及保留关系，避免以旧副本覆盖后来保留的后代。
- ContainerShape 默认拒绝解组，Group 显式允许。解组计划重新检查能力、父级、位置和子节点身份/顺序；准备后源结构变化时明确拒绝，不丢弃新子节点。
- SVG 先解码完整子规格，再以实际 SVG 子节点覆盖 CLI 创建模板（包括空列表），完整装配后运行导入检查；缺少必要部件不能由创建模板悄悄补齐。

## 取舍与边界

预演当前采用 O(n) 临时结构关系复制，便于可靠验证跨父级分组、解组、移入与多层复合约束。代价是结构命令的校验开销增加；没有测量或预写最终 Git 指标。历史仍保存局部变更、位置和图形身份，不保存整份候选文档。

基本写操作不逐项调用插件策略，使合法中间态及失败补偿不被阻断。策略与规格构造必须遵守只读/确定性或构造新对象的契约；框架不承诺补偿插件任意外部副作用。内部候选、绑定器和写接口不属于插件公开 API。

## 实际验证与修正

composite-subtree.test.ts 覆盖完整创建与身份保持、内部/外部 id 冲突、叶子子规格、必要部件删除/移走/分组保护、整棵删除、附加节点、重排、嵌套解组、构造及部分写入失败、undo/redo 失败、最终父级及临时空组状态。

复查发现重做可能以初始副本覆盖保留后代，已改为首次安装后普通重新接入；过期解组计划会漏掉后加子节点的回归实际先失败，再补源结构检查。composite-import.test.ts 验证完整嵌套读回、不伪造缺失部件，以及真实读回失败保留原文档、默认路径与历史。实际结果见 [报告第 10 节](../README.md)。

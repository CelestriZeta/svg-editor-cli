# Phase 1 测试清单

本文件列出测试项；勾选项仅表示已获得实际验证，不代表业务功能已经完成。完整命令和结果记录在 `doc/README.md`。

## 工程基线

- [x] TypeScript 严格类型检查
- [x] 测试运行器可启动并执行 TypeScript 测试
- [x] 生产代码构建到 `dist/`
- [ ] 领域层不导入终端、文件系统或 XML 库
- [ ] 一类一文件且文件名与类名一致
- [ ] 按名字分派只出现在 `CommandDispatcher` 和 `ShapeFactory`

## 领域与 Composite

- [ ] 六种图形创建参数、几何属性和省略样式
- [ ] id 全局唯一、大小写敏感、外部导入补 id 及碰撞规避
- [ ] `move`、`scale`、`set`、`delete` 对叶子和容器统一生效
- [ ] 容器操作递归作用于全部子孙
- [ ] `scale` 同乘位置和尺寸，非正数失败且状态不变
- [ ] `create ... in` 校验容器存在且类型为 `g`
- [ ] `group`、`ungroup`、`addto`、`front`、`back` 的父级和顺序
- [ ] 祖先与子孙同时分组时失败且不形成环
- [ ] 根级容器拒绝 `ungroup`
- [ ] Visitor 按进入、递归、离开顺序遍历，并支持跳过子树
- [ ] 多节点操作先完成全部校验再提交，不产生部分修改

## 局部变更记录

- [ ] create 撤销后恢复节点、父级和位置
- [ ] delete 撤销后恢复完整子树、父级和原顺序
- [ ] move、scale、set 恢复旧值及属性存在性
- [ ] group、ungroup、addto、front、back 恢复父级和有序子列表
- [ ] redo 复用首次记录，不重新分配 id 或反向计算几何
- [ ] 失败命令不产生变更记录

## 命令、执行器与历史

- [ ] 命令只校验和转发，不直接修改子节点集合、id 索引或文件
- [ ] Dispatcher 按名称创建命令，未知命令返回 `error:`
- [ ] `help` 与命令描述符同源
- [ ] Executor 串行执行并等待 IO 完成
- [ ] 一条编辑命令是一个 undo 单元
- [ ] 新编辑清空 redo
- [ ] 查询和无参 `canvas` 不进入历史
- [ ] `init`、`read`、`save`、修改尺寸的 `canvas` 建立历史屏障
- [ ] undo/redo 恢复成功后才转移历史栈

## 文档与 SVG IO

- [ ] `init` 默认创建 800x600 画布
- [ ] `read` 先构造并校验候选文档，成功后才替换会话
- [ ] `save` 无参数使用当前默认路径
- [ ] `save` 显式路径成功后成为新的默认路径
- [ ] `init` 清除默认路径
- [ ] 文件不存在、不可读或不可写时保留原文档和原路径
- [ ] 保存先写同目录临时文件，成功后替换目标
- [ ] 缺 id 自动分配且打印警告
- [ ] 重复 id、未知元素和不支持属性明确报错
- [ ] XML 命名空间、文本和属性转义正确
- [ ] 保存再读回的模型语义等价

## CLI

- [ ] `svg>` 提示符和逐行脚本回放
- [ ] 只有整行开头的 `#` 是注释
- [ ] 双引号保留含空格文本
- [ ] 颜色参数中的 `#` 不被当作注释
- [ ] 浮点数参数正确解析
- [ ] `tree` 输出属性内联，并支持整棵树和子树
- [ ] `show` 输出父级和属性明细
- [ ] 无文档时 `help` 可用，其他命令返回统一错误
- [ ] 成功摘要和错误输出符合需求格式
